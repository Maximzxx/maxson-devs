PROYECTO PERSONAL · BUILD DE QA

GT7 Copilot.

Un prototipo de copiloto de práctica para Gran Turismo 7. La idea es ayudar a estudiar Spa-Francorchamps con un mapa 2D, indicaciones de conducción y una base para experimentar con telemetría.

Descargar build de QA ↗ Ver código fuente ↗

Por ahora, el paquete disponible es una AppImage para Linux x86_64. La compatibilidad con otros sistemas todavía no está publicada.

LA IDEA

Aprender la pista, curva a curva.

GT7 Copilot nació de mi inexperiecia en simuladores de conduccion lol, al no saber manejar y desconocer la mayoria de circuitos decidi crear una aplicacion personal capaz de enseñarme los trazados, circuitos,curvas y detalle tecnicos tambien ser capaz de leer mis vueltas y dar recomendaciones cuya funcion sigo trabajando.

El prototipo incluye dos estilos de instructor —simple y tipo copiloto de rally— y está pensado para evolucionar con información de conducción más útil.

BAJO EL CAPÓ

Herramientas y enfoque

01

C++ y Qt Quick / QML

Interfaz de escritorio con una estética oscura y componentes visuales para el mapa y el instructor.

02

Mapa de Spa

Vista 2D del circuito como base para estudiar trazada, sectores e indicaciones.

03UDP experimental

Infraestructura inicial para recibir telemetría y probar comunicación local. La conexión con una consola real aún necesita validación.

04

Pruebas de QA

La retroalimentación de otras personas ayudará "demasiado porque no tengo mucha imaginacion" a encontrar errores y priorizar mejoras antes de ampliar el proyecto.

PARTICIPA EN EL QA

Prueba el prototipo

Esta es una build temprana. Antes de probarla, ten en cuenta lo siguiente:

  • Necesitas un PC Linux de 64 bits para usar el paquete publicado actualmente. tambien se pueden usaar maquinas virtuales pero no garantizo su funcionalidad
  • Para probar el flujo de juego, necesitas Gran Turismo 7 y acceso al circuito de Spa-Francorchamps.
  • Una PS5 es preferible para las pruebas de telemetría real, pero esa conexión todavía no está verificada en todos los entornos.
  • Si no tienes consola a mano, consulta el repositorio para ver las opciones de prueba disponibles; la telemetría simulada es una vía experimental.

Importante: no es una versión final. Algunas funciones pueden estar incompletas y los resultados de telemetría no deben considerarse fiables hasta que se validen.
